WishingWall.co homepage mock asset pack

Source
------
wishingwall_homepage_mock_full.png is the complete generated homepage concept.

Important
---------
The homepage mock was generated as one flattened raster image. These files are
cropped/extracted from that mock rather than original layered/vector source assets.

Files ending in "_transparent.png" use best-effort background removal and may need
minor cleanup before production use.

The guestbook UI preview is a crop from the concept mock and is useful as a visual
reference/prototype image, not as editable application UI.

For production, the line-art icons and mountain mark should ideally be recreated
as SVGs so they remain crisp at all sizes.
